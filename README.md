- Developed authentication, role-based access control, and real-time data handling.
- Supported thousands of active users across multiple branches.

### 2. Clinic Management System — Healthcare ERP

**C# | .NET Framework | SQL Server | Crystal Reports**

- Led development of a desktop-based healthcare ERP solution.
- Developed patient registration, medical records, and visit history modules.
- Implemented medicine inventory management with balance tracking, stock updates, and expiration alerts.
- Integrated Crystal Reports for patient history, billing, and medicine issuance.

- Built inventory workflows for purchase entries, stock tracking, invoices, and delivery challans.
- Automated HR workflows covering employee records, payroll, and leave management.
